## 带状疱疹
2026 年 8 月 12 日。最近写设计文档，加班、压力比较多，比较大。在晚上吃了一袋麻辣牛肉后，感觉右手臂开始出现刺痛感。在 23 年大概相似的时间节点，就得过一次。当时不知道是什么，过了两天手臂上出现了两个水泡，手臂刺痛感消失了，以为是湿疹，还用药膏涂，结果越涂问题越大。
似乎是病毒一直在潜伏，如果你身体压力大，抵抗力不足时，病毒可能就会表现出来。这么说此前我有过几次晚睡之后，半侧脸部刺痛，可能也是相同原因。
已经开始服用阿昔洛韦，希望这次不要再长泡了。。。
